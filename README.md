# SANS analysis of two-phase nanoscale lipid vesicles across the co-existence temperature region using ML-CREASE

A mixture of DPPC and DLPC lipids is known to form nanoscale vesicles that show a gel-liquid phase coexistence in the vesicle shell. Based on microscopy of giant microscale vesicles, it is hypothesized that the phase boundaries between the gel and the liquid phase in nanoscale vesicles is irregular (do not adopt well defined shapes). In order to study these irregularly shaped gel and liquid domains in the nanoscale vesicle shell, small angle neutron scattering (SANS) data is collected for a mixture of dueterated DPPC (dDPPC) and DLPC lipids across the gel-liquid phase coexistence temperatures (between 9C and 24C). Interpreting the obtained SANS data is complicated due to the lack of scattering models to account for the presence of multiple phase domains in the vesicle shells (lateral heterogeneity) and the irregular shapes of these phase domains. In this repository, we share all the Python scripts to successfully implement the ML-CREASE workflow to analyze the SANS data for these two-phase nanoscale vesicles by accounting both for lateral heterogeneity and the irregular phase boundaries between the domains.

A brief description of all the codes included in this repository is provided below.

The Five Steps of the CREASE-GA Loop
----------------------------------------------------------
**Step 1: Identification of the relevant structural features for the system -** For dDPPC-DLPC vesicles that display lateral heterogeneity in the shells, we have identified four structural features to study the SANS data. The identified structural features are, (1): The core radius of the vesicles (Rcore), (2): The liquid phase volume fraction in the vesicle shells (vliq), (3): The number of isolated liquid domains in the vesicle shell (Ndom), and (4): The scattering length density contrast ratio of the liquid to the gel phase (SLDL/SLDG). The shell thickness of the vesicles is not varied as a structural feature as it is not expected to have an influence on the shapes of the scattering profiles in the studied q-range. 

**Step 2: Generating a dataset of 3D representative structures by varying the values of structural features -** To generate 3D representative structures of nanoscale lipid vesicles with lateral heterogeneity and irregularly shaped phase domains we have provided the following scripts. We have provided 3 separate scripts for structure generation. (1) Python script that randomly places the isolated liquid phase domains in the spherical shell. (2) Python script that takes these randomly placed isolated liquid domains as an input and clusters the liquid domains as close to each other as possible. (3) Python script that takes these randomly placed isolated liquid domains as an input and evenly spreads the liquid domains across the spherical shell 

**Step_2_Struc_Gen/Randomly_Placed/inputscript_crwsg.py** This Python script allows the user to set the parameters and file names for performing the constrained random walk in spherical grids. The user can set the desired parameter values and output file names in this script and run using the command python/python3 inputscript_crwsg.py.

**Step_2_Struc_Gen/Randomly_Placed/constr_rand_walk_sph_grids.py** This is a module for performing a constrained random walk in spherical grids. A constrained random walk in spherical discretizes the spherical shell and allows for the generation of irregularly shaped domains in the spherical shell. The random walk in spherical grids is constrained by the user inputs for liquid phase volume fraction and the number of isolated liquid domains. An isolated liquid domain is as a collection of connected liquid phase grids that is surrounded by gel phase grids in all directions. The random walk in spherical grids algorithm iterates until the user-specified constraints are met. After completion of the constrained random walk, this module outputs the 3D representation of the generated two phase vesicle within a point scatterers representation (.dump files). The .dump files can be visualized using OVITO and/or used for further computation (e.g., scattering profile computation). This module also outputs a flattened representation of the two-phase spherical vesicle for ease of visualization of the liquid-gel phase boundaries and the isolated liquid domains.

**Step_2_Struc_Gen/Clustered/inputscript_clustered.py** This Python script allows the user to set the parameters and file names for performing the clustering (bringing together) of the randomly placed isolated liquid domains. The user can set the desired parameter values, input file name, and output file names in this script and run using the command python/python3 inputscript_clustered.py. 

**Step_2_Struc_Gen/Clustered/clustered_domains.py** This is a module for performing the clustering of isolated liquid domains in the two-phase vesicle shell. The clustering algorithm brings the liquid domains as close to each other as possible while still preserving the number of isolated liquid domains set by the user. After completion of the clustering of liquid domains, this module outputs the 3D representation of two phase vesicle within a point scatterers representation (.dump files). The .dump files can be visualized using OVITO and/or used for further computation (e.g., scattering profile computation). This module also outputs a flattened representation of the two-phase spherical vesicle for ease of visualization of the liquid-gel phase boundaries and the isolated liquid domains.

**Step_2_Struc_Gen/Evenly_Spaced/inputscript_even_spaced.py** This Python script allows the user to set the parameters and file names for performing the even spacing (spreading out the isolated liquid domains across the spherical shell) of the randomly placed isolated liquid domains. The user can set the desired parameter values, input file name, and output file names in this script and run using the command python/python3 inputscript_even_spaced.py. 

**Step_2_Struc_Gen/Evenly_Spaced/evenly_spaced_domains.py** This is a module for performing the even spacing of isolated liquid domains in the two-phase vesicle shell. The even spacing algorithm spreads out the liquid domains while still preserving the number of isolated liquid domains set by the user. After completion of the even spacing of liquid domains, this module outputs the 3D representation of two phase vesicle within a point scatterers representation (.dump files). The .dump files can be visualized using OVITO and/or used for further computation (e.g., scattering profile computation). This module also outputs a flattened representation of the two-phase spherical vesicle for ease of visualization of the liquid-gel phase boundaries and the isolated liquid domains.

**Step 3: Computing the scattering profile for every 3D representative structure generated in step 2 -** To compute the physics based azimuthally averaged 1D SANS profile for every 3D representative structure of two-phase lipid vesicles (generated in step 2), we have provided the following two Python scripts.

**Step_3_Scattering_Comp/input_1Dscatter.py** This Python script accepts input from the user for the folder name and path containing all the 3D representative strucures filled with point scatterers for which the scattering profiles need to be computed. The user can also specify the number of orientational directions across which the scattering profile needs to be azimuthally averaged. The user can also specify the path and name of output file in which to store the computed scattering profiles. To compute the scattering profile from a 3D representative structure run this script using the command 'python input_1Dscatter.py' or 'python3 input_1Dscatter.py' 

**Step_3_Scattering_Comp/generate_1Dscatter.py** This Python script contains the necessary functions and commands to compute the physics based scattering amplitude vectors separately for the gel and the liquid phases. Store the gel and liquid phase point scatterers in separate dump files before using this script. This code performs the scattering amplitude computation for every point scatterer dump file in the designated folder specified by the user. This code uses GPU parallelization to accelerate the computation of scattering amplitude vectors. Outputs the real and imaginary parts of the scattering amplitudes for every q vector (with magnitude and direction) for further processing.  

**Step 4: Training an XGBoost ML model to link a set of structural features to its computed scattering profile -** In step 4, we train a surrogate machine learning (ML) model using the set of structural features and its corresponding scattering profiles generated in the previous steps. We randomly select 80% of the dataset for training and 20% of the dataset for testing the XGBoost ML model. The XGBoost ML model improves the computational efficiency of CREASE by bypassing the 3D representative structure generation and physics based scattering computation. 

**step_4/xgboost_training.py** This Python script accepts the training dataset containing a set of structural features, q values, and the computed scattering intensities [I(q)] in tabular form (.csv file) and uses Bayesian optimization to tune the decision trees of the XGBoost ML model. The python script outputs the trained XGBoost ML model (.json file). To train the XGBoost ML model run this script using the command 'python xgboost_training.py' or 'python3 xgboost_training.py'.

**Step 5: Using the CREASE GA optimization loop to identify structural feature distributions corresponding to the input experimental profile -** In step 5, we incorporate the trained XGBoost ML model into the CREASE genetic algorithm (GA). The genetic algorithm is an optimization loop that takes an experimental scattering profile as input and outputs the structural feature values, fitness, and predicted I(q) from CREASE for the last generation of candidate solutions. 

**Step_5_CREASE_GA/inputscript_CREASE_GA.py** This Python script is an input script for running the CREASE-GA optimization loop. The user can specify the range for each structural feature, the number of generations of CREASE optimization for each trial, and the number of independent CREASE-GA trials. The user can also specify the input file containing the experimental SANS data and the desired xgboost surrogate ML model to be used within the CREASE-GA optimization loop. To run the CREASE-GA optimization loop set the desried values for the parameters, the desired input files, and the desired names of output files and run using the command 'python3 inputscript_CREASE_GA.py' or 'python3 inputscript_CREASE_GA.py'. The experimental profiles are expected to have 4 columns of data with commented out additional text if any. The 4 columns correspond to the q values, scattering intensities [I(q)], the errors in I(q), and the resolution of q values, respectively.

**Step_5_CREASE_GA/multiple_runs_res_smear_CREASE_engine.py** This Python script accepts an experimental scattering profile as input and iterates over generations of candidate solutions until the fitness of the candidate solutions within a generation are converged. The python script runs for a user-specified number of generations with the user-specified number of candidate solutions (individuals) each, and performs a user-specified number of independent trials of CREASE-GA optimization. This script also performs the resolution smearing of computed scattering intensities with a user-specified number of smearing points. This script outputs the structural features and fitness of individuals corresponding to the last GA generation of every independent CREASE-GA trial. This script also outputs the predicted I(q) for the best performing CREASE-GA candidate across all the independent trials and the standard deviation in predicted I(q) between the best performing candidate solution of every independent trial.
